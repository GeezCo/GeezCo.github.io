# 脚本使用说明

## 📄 加密上传简历

### 用法

```bash
./script/upload-resume.sh <简历文件路径> [commit消息]
```

### 示例

```bash
# 基本用法
./script/upload-resume.sh ~/Downloads/resume.pdf

# 自定义 commit 消息
./script/upload-resume.sh ~/Downloads/resume-2026.pdf "更新2026年简历"
```

### 功能

1. ✅ 复制简历到 `api/private/`
2. ✅ 使用 **AES-256-GCM** 加密（与项目现有加密方案一致）
3. ✅ 使用 `.env.local` 中的 `SITE_SECRET` 作为密钥
4. ✅ 自动删除原文件（仅保留 `.enc` 加密版本）
5. ✅ 自动添加到 Git 并提交
6. ✅ 可选推送到远程仓库

### 前置要求

1. **Node.js** 已安装
2. **`.env.local`** 文件存在且包含 `SITE_SECRET`

```bash
# .env.local 示例
SITE_SECRET=your_secret_key_here
```

### 加密方式

- **算法**: AES-256-GCM
- **密钥派生**: SHA-256(SITE_SECRET)
- **输出格式**: `IV(12字节) + AuthTag(16字节) + Ciphertext`
- **加密脚本**: `api/scripts/encrypt-pdf.mjs`

### 解密方法

使用项目的解密 API 或创建对应的解密脚本。

### 注意事项

- 🔐 `SITE_SECRET` 请妥善保管，不要提交到 Git
- 📦 `.enc` 文件会提交到 Git（安全）
- 🗑️ 原始 PDF 文件会自动删除
- ⚠️ 原始 PDF 已添加到 `.gitignore`（`api/private/*.pdf`）
