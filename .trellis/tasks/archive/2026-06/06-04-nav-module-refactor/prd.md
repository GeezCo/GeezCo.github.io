# brainstorm: 顶部导航重构 - 模块化菜单设计

## Goal

将顶部导航菜单从扁平结构改为模块化设计，整合"主页/博客/文档/工具"四个模块，为未来新增模块预留扩展空间，同时保持菜单简洁清晰。

## What I already know

### 当前导航结构
- **Header.astro** (`/src/components/Header.astro`): 扁平菜单，包含：
  - Logo (GeezCo)
  - 搜索按钮（带快捷键）
  - 导航链接：首页、博客、文档、工具、关于、赞赏、RSS
  - 主题切换按钮
- 所有链接平铺展示，移动端已有响应式适配

### 现有页面模块
1. **首页** (`/`) - 展示最新文章和功能导航
2. **博客** (`/blog`) - 文章列表和搜索
3. **文档** (`/doc`) - 技术文档系统
4. **工具** (`/tools`) - 工具集合页面
5. **关于** (`/about`) - 个人/组织介绍
6. **赞赏** (`/sponsor`) - 支持页面

### 技术约束
- Astro 框架
- 响应式设计（桌面 + 移动端）
- 暗黑模式支持
- 当前使用 CSS 变量系统 (`var(--color-primary)` 等)

## Assumptions (temporary)

- 需要将"首页/博客/文档/工具"合并为下拉菜单或模块化入口
- "关于/赞赏/RSS"可能保持独立，或归入"更多"分类
- 搜索按钮和主题切换保持当前位置
- 需要桌面端下拉菜单 + 移动端汉堡菜单

## Requirements (MVP - 最小可行版本)

### 导航结构
- **首页按钮**作为主入口：
  - 点击跳转到 `/`
  - 悬停时显示下拉菜单（桌面端）
  - 下拉菜单包含：博客、文档、工具
  - 为未来新模块预留扩展槽位
- **独立保留**：关于、赞赏
- **固定元素**：搜索按钮、主题切换
- **移到页脚**：RSS 链接

### 交互设计
- **桌面端**：鼠标悬停展开下拉菜单，点击"首页"跳转
  - 下拉菜单样式：卡片式（带图标和描述）
  - 示例布局：
    ```
    📝 博客 - 技术文章与思考
    📚 文档 - 系统化知识库
    🛠️ 工具 - 实用开发工具
    ```
- **移动端**：汉堡菜单（`☰` 图标）
  - 点击展开侧边抽屉或全屏菜单
  - 显示所有导航项（扁平列表）

### 页面内导航发现
- **博客页面**：无侧边栏，按年份分组展示文章卡片
- **文档页面**：
  - 有 `DocSidebar.astro` 左侧边栏
  - 支持多级导航树（父项 + 子项）
  - 当前页面高亮显示
  - 移动端隐藏侧边栏（`@media max-width: 767px`）
- **顶部下拉菜单不需要与文档侧边栏联动**（独立系统）

### MVP 范围明确
- ✅ 实现桌面端悬停下拉 + 卡片样式
- ✅ 实现移动端汉堡菜单
- ✅ 当前页面在顶部菜单高亮
- ✅ 暗黑模式支持
- ✅ 基础键盘导航（Tab/Enter）
- ❌ 不做二级子菜单（未来扩展）
- ❌ 不做无 JS 降级（依赖现代浏览器）
- ❌ 不改动文档侧边栏系统

## Technical Approach

### 组件设计
1. **Header.astro** - 重构现有顶部导航
   - 添加下拉菜单逻辑（悬停/点击）
   - 保留搜索按钮和主题切换
   - 移除 RSS 链接

2. **NavDropdown.astro**（新建）- 桌面端下拉菜单
   - 卡片式布局
   - 图标 + 标题 + 描述
   - CSS 悬停动画（opacity + translateY）

3. **MobileMenu.astro**（新建）- 移动端汉堡菜单
   - 侧边抽屉或全屏菜单
   - 包含所有导航项
   - 背景遮罩 + 滑入动画

4. **Footer.astro** - 更新页脚
   - 添加 RSS 链接

### 技术栈
- Astro 原生组件（无需 React/Vue）
- CSS 动画（transition + transform）
- 轻量 JavaScript（菜单开关状态）
- 复用现有 CSS 变量系统

### 实现顺序
1. 创建 `NavDropdown.astro` 和 `MobileMenu.astro` 组件
2. 重构 `Header.astro` 集成新组件
3. 更新 `Footer.astro` 添加 RSS 链接
4. 添加当前页面高亮逻辑
5. 测试响应式和暗黑模式
6. 优化动画和可访问性

## Out of Scope (explicit)

- 二级子菜单支持（如"文档"下的子分类）
- 无 JavaScript 降级方案
- 触摸设备特殊优化（iPad 等）
- 与文档侧边栏的联动高亮
- 菜单项拖拽排序功能
- 国际化/多语言支持
