# 将博客升级为 GeezCo 综合门户网站

## Goal

将当前的博客网站升级为 GeezCo 的综合门户网站，不仅展示文章，还要支持多个系统的文档入口、工具集合等。主页需要重新设计为门户首页，展示各个板块的入口和最新动态。

## What I already know

### 当前实现
- 主页文件：`src/pages/index.astro`
- 当前定位：个人技术博客
- 主要内容：文章列表（21 篇）
- 已有板块：
  - 博客文章（`/blog`）
  - 在线工具（`/tools`）
  - 赞助页面（`/sponsor`）
  - 简历下载（`/resume`）

### 新的愿景
- **定位升级**：从个人博客 → GeezCo 综合门户
- **多系统支持**：
  - 博客系统（已有）
  - 文档系统（新增 `/doc`）
  - 工具系统（已有 `/tools`）
  - 未来可能的其他系统
- **文档结构**：`/doc/xxx系统` 形式组织各系统文档

### 技术栈
- Astro 6 静态站点生成
- 当前已有 Tailwind CSS v4
- 响应式设计 + 深色模式

## Assumptions (temporary)

- 主页需要展示各个板块的入口卡片
- 文章列表不再是主页的主要内容，而是其中一个板块
- 需要为未来的系统预留扩展空间
- 文档系统可能需要独立的导航和布局

### 2. 文档系统的实现方式

**方案 A：Astro Content Collections（推荐）**
```
src/content/
  ├── blog/          # 博客文章
  └── docs/          # 文档
      ├── system-a/  # 系统 A 文档
      ├── system-b/  # 系统 B 文档
      └── ...
```
- ✅ 与博客系统一致
- ✅ 支持 Markdown + frontmatter
- ✅ 类型安全

**方案 B：独立文档框架（如 Starlight）**
```
/doc → 独立的 Starlight 站点
```
- ✅ 功能强大（搜索、侧边栏、版本管理）
- ❌ 需要额外配置和维护

你希望文档系统如何实现？

## Requirements

### 1. 主页重构为门户首页

**布局结构（卡片式门户）**
- Hero 区域：
  - 标题：GeezCo
  - 副标题：技术创新 · 开源分享 · 持续学习
  - 简短介绍文案
  
- 板块卡片区域（3 列网格，移动端 1 列）：
  - 📝 博客卡片
    - 标题：博客
    - 描述：技术文章分享
    - 统计：X 篇文章
    - 按钮：进入博客
    - 链接：`/blog`
  
  - 📚 文档卡片
    - 标题：文档
    - 描述：系统文档中心
    - 统计：X 个系统
    - 按钮：查看文档
    - 链接：`/doc`
  
  - 🛠️ 工具卡片
    - 标题：工具
    - 描述：在线工具集
    - 统计：X 个工具
    - 按钮：使用工具
    - 链接：`/tools`

- 最新动态区域：
  - 标题：最新动态
  - 显示最新 3 篇文章（使用现有 PostCard 组件）
  - 底部按钮：查看所有文章 → `/blog`

### 3. 创建文档系统基础结构

**Content Collection 配置**
- 在 `src/content/config.ts` 中添加 `docs` collection
- Schema 包含：title, description, system, order, pubDate

**目录结构**
```
src/content/
  ├── blog/          # 现有博客文章
  └── docs/          # 新增文档
      ├── system-a/  # 系统 A 文档（示例）
      │   └── index.md
      └── README.md  # 文档说明
```

**文档首页 `/doc`**
- 显示所有系统的文档入口
- 卡片式布局
- 每个系统显示：名称、描述、文档数量、进入按钮

**文档详情页 `/doc/[system]`**
- 侧边栏导航（显示该系统的所有文档）
- 主内容区域（Markdown 渲染）
- 面包屑导航
- 上一篇/下一篇导航

### 4. 更新导航栏

**顶部导航链接**
- 首页 `/`
- 博客 `/blog`
- 文档 `/doc`
- 工具 `/tools`
- 关于 `/about`（可选）

### 5. 样式和交互

- 所有卡片支持 hover 效果
- 深色模式适配
