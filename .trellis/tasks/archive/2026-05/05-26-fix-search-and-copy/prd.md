# 修复搜索结果展示和代码复制按钮

## Goal

修复两个问题：
1. 搜索结果显示混乱，没有分块加载
2. 代码块复制按钮没有生成

## Current Issues

### 问题 1：搜索结果混乱

**现状**：
- 搜索结果列表显示混乱
- 没有实现分块加载（应该每次显示 10 条，点击"加载更多"）
- 搜索结果应该只显示：标题 + 内容匹配部分（前后一两句）

**期望**：
- 清晰的卡片式布局
- 每次显示 10 条结果
- 底部有"加载更多"按钮
- 每个结果卡片显示：标题（高亮关键词）+ 匹配内容片段（前后各一句）+ 标签 + 日期

### 问题 2：复制按钮不显示

**现状**：
- 代码块没有复制按钮
- 代码和样式看起来都正确

**可能原因**：
- 选择器 `:global(pre:hover) [data-copy-btn]` 可能有问题
- 需要改为 `:global(pre):hover [data-copy-btn]`

## Requirements

### 搜索功能

1. **结果展示**
   - 每个结果卡片包含：
     - 标题（高亮关键词）
     - 内容匹配片段（前后各一句，最多 150 字符）
     - 标签（最多 3 个）
     - 发布日期
   - 卡片式布局，清晰分隔

2. **分块加载**
   - 初始显示 10 条结果
   - 底部显示"加载更多"按钮（如果还有更多结果）
   - 点击后再加载 10 条
   - 全部加载完后隐藏按钮

3. **排序功能**
   - 保持现有的三种排序：相关性、标题匹配、最新发布
   - 切换排序时重置分块加载状态

### 复制按钮

1. 修复选择器，确保悬浮时按钮可见
2. 保持 GitHub 风格的视觉效果
3. 点击复制后显示绿色对勾

## Acceptance Criteria

- [ ] 搜索结果以卡片形式清晰展示
- [ ] 初始只显示 10 条结果
- [ ] 有"加载更多"按钮，点击后加载下一批
- [ ] 全部加载完后按钮消失
- [ ] 每个结果显示标题、内容片段、标签、日期
- [ ] 关键词在标题和内容中高亮显示
- [ ] 代码块悬浮时右上角显示复制按钮
- [ ] 点击按钮成功复制代码
- [ ] 复制后显示绿色对勾 2 秒

## Technical Approach

### 搜索结果修复

1. 修改 `SearchModal.astro` 的 `renderResults` 函数
2. 添加分块加载逻辑：
   - 维护 `displayedCount` 变量（已显示数量）
   - 每次渲染 10 条
   - 添加"加载更多"按钮
3. 优化摘要提取：
   - 使用 Pagefind 的 `excerpt` 字段
   - 限制长度为 150 字符
   - 保留 `<mark>` 标签用于高亮

### 复制按钮修复

修改 `PostLayout.astro` 第 200 行：

```css
/* 修改前 */
:global(pre:hover) [data-copy-btn] {
  opacity: 1;
}

/* 修改后 */
:global(pre):hover [data-copy-btn] {
  opacity: 1;
}
```

## Out of Scope

- 不改变搜索的核心逻辑（Pagefind API 调用）
- 不修改排序算法
- 不添加新的搜索功能
