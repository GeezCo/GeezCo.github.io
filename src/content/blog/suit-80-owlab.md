## 什么是客制化键盘

量产键盘（Filco、Leopold、Cherry 等）买来直接用。客制化键盘是像组装台式机一样，自己买套件、轴体、键帽——每一部分都是独立选购的。

客制化的价值不在于"比量产好"——量产键盘经过大厂品控和调教，手感往往很稳定。客制化的价值在于：
- 每个零件都可以根据自己的偏好选择
- 手感和声音可以通过不同组合调整
- 过程中对键盘结构的理解本身就是收获

Suit 80 是 Owlab 出品的一款 80% 布局（TKL）客制化套件。

## 组装步骤

### 1. 润卫星轴

卫星轴的作用是稳定大键（空格、Shift、Enter 等），防止大键按下时倾斜。润滑直接影响大键的手感和声音。

**润滑要点**：

```
卫星轴结构（简化）：
  ┌─────────────────────┐
  │    卫星轴底座        │  ← 十字菊花（stem 滑动通道）
  │  ┌─────────────┐    │
  │  │  十字菊花     │    │  ← 两侧薄润
  │  └─────────────┘    │
  └─────────────────────┘
          ↑
     钢丝穿过
          │
  ┌───────┴───────┐
  │   钢丝拐角     │  ← 厚润（减少钢丝震动杂音）
  │   短边尽头     │  ← 厚润
  └───────────────┘
```

具体操作：
- 十字菊花（stem 滑动的通道）底座两侧**薄薄涂一层**——多了会发粘
- 钢丝拐角处根据需求**厚润**
- 钢丝短边尽头**厚润**
- 涂完不需要太规整，从后面插入轴座会自然摊平

### 2. 安装卫星轴

```
安装顺序：
  1. 大键位位置贴上特氟龙胶带（绝缘层）
  2. 放上轴下垫（在 PCB 和定位板之间）
  3. 将卫星轴装到 PCB 上
  4. 拧卫星轴螺丝
```

**关键警告**：拧卫星轴螺丝时**一定要带着垫子拧**。如果 PCB 没有垫子隔离，金属螺丝可能接触 PCB 电路导致短路。

### 3. 铺定位板

依次铺上：
1. 夹心棉（在 PCB 和定位板之间）
2. 定位板（固定轴体的板子）

**注意**：Tiger 80 Lite 定位板在卫星轴处的开孔非常紧，需要慢慢压下去。不要用蛮力——PC 材质虽然软，但开孔处可能卡住卫星轴。

### 4. 上轴体

轴体插到定位板 + PCB 上。两种方式：

- **无针脚的轴**（如部分光学轴）：直接按下去即可
- **有金属针脚的轴**（如 TTC、Gateron、Cherry MX）：让有针脚的一边先倾斜插入 PCB 轴座，再扣紧另一边

这样做是为了避免金属针脚受力弯曲——弯了的针脚很难复原，轴就废了。

### 5. 安装 Gasket 硅胶粒

Gasket Mount 是客制化键盘的主流固定方式之一。跟传统螺丝固定（Top Mount）不同，Gasket 结构用硅胶粒夹住定位板：

```
传统 Top Mount：
  定位板 → 螺丝 → 外壳
  硬连接，打字震动直接传导

Gasket Mount：
  定位板 → 硅胶粒 → 外壳
  软连接，硅胶吸收震动，手感更软弹
```

具体操作：
- 在定位板上下两边突出的"耳朵/胳膊"上安装硅胶粒
- 每个耳朵两端都要装
- 硅胶粒夹在定位板和外壳之间

### 6. 安装子板

USB 子板连接 PCB 和外部 Type-C 接口：

1. 子板装入底壳并上好螺丝
2. FFC 排线连接子板和 PCB

> 排线有防呆口——方向不对插不进去，一般不会出错。

### 7. 扣外壳

**关键步骤**：扣外壳前，把上壳两侧突出的加强筋剪掉。

如果不剪——加强筋会卡住定位板，外壳盖不严，而且还可能压弯定位板。

### 8. 上螺丝

使用包装中**最细最长**的黑色螺丝。不要用错——粗螺丝是其他用途的。

### 9. 连线测试

插上 Type-C 线连接电脑：
- 用键盘测试工具（如 VIA、Vial 或者网页版 key tester）逐个按键测试
- 确认所有轴体正常触发
- 确认大键没有卡涩或异响
- 测试 RGB 灯效（PCB 支持的话）

**先测试再上键帽**——如果某个轴没装好，键帽拆下来比重装轴体麻烦。

## 打字音

Suit 80 + PC 定位板 + 底棉 + Gasket 结构的组合出来的声音通常是"麻将音"——闷而清脆，在客制化圈中性价比较高。

影响声音的因素：
- **定位板材质**：PC（软、闷）、FR4（均衡）、铝（硬、脆）、碳纤维（硬、脆）
- **底棉/夹心棉**：有棉更闷更干净，无棉更清脆但有空腔音
- **轴体**：线性轴声音比段落轴更纯粹
- **桌面/桌垫**：木板桌面 vs 玻璃桌面 vs 桌垫，都会影响声音

## 新手常见问题

**Q：轴体怎么选？**
A：先确定线性/段落/Clicky，再选克数（轻 45g / 中 55g / 重 65g+）。新手推荐线性轴（如 Gateron Yellow Pro、TTC Gold Pink），不容易踩坑。

**Q：PCB 支持热插拔吗？**
A：Suit 80 PCB 支持热插拔（轴座已经在 PCB 上焊好了），直接插拔轴体即可，不需要焊接。

**Q：为什么不买成品键盘？**
A：这是个好问题。如果你对键盘没有特别的偏好和要求，买量产更省事。如果你对线性轴 45g vs 55g 的差异能感知出来，或者受不了钢丝声的杂音，客制化才有意义。

## 总结

- 组装顺序不能乱——先润卫星轴，再装 PCB → 定位板 → 轴体 → Gasket → 外壳
- 拧卫星轴螺丝时保持垫子在位，防止短路
- 定位板开孔紧是正常的，慢慢压
- 有针脚的轴体要从针脚一侧倾斜插入
- 上壳加强筋不剪会影响外壳密合
- 上键帽前先用测试工具逐个检查
