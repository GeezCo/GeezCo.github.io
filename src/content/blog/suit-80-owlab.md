### ⌨️ 组装：

1. 先润卫星轴，十字菊花的底座两侧薄润，钢丝的拐角处根据自己需求厚润，钢丝短边尽头厚润 （不需要太规整，从后面插入轴座会摊平）。
2. 大键位贴上特氟龙胶带，放上轴下垫，安装卫星轴。
{% note warning %}要带着垫子拧卫星轴螺丝，防止pcb因为金属螺丝段路。{% endnote %}
3. 依次铺上夹心棉、定位板，注意80 lite定位板卫星轴处开孔很紧，慢慢扣下去。
4. 上轴体，选自己喜欢的。
{% note warning %}如果TTC之类的只有俩金属针脚，可以先让有针脚的一边稍微倾斜先进去然后扣紧即可。{% endnote %}
5. 在定位板上下两边突出的“胳膊”上装硅胶粒，每个胳膊两端都要装。
6. 子板装底壳，并上好螺丝，装到pcb（注意子板安装线材顺序，有防呆口一般不会错，但防呆不防傻 -_-）
7. 扣上外壳。
{% note warning %}扣之前记得把上壳两侧突出的加强筋剪掉，不然会卡定为板盖不严（👉这样的手指形状）{% endnote %}
8. 上外壳螺丝（包装里细黑的最长的那个） 。
9. 连线测试。
