## 核心要素

| 要素 | 说明 |
|------|------|
| 适应值 | 区分染色体优劣的指标 |
| 评估函数 | 计算适应值 |
| 选择算子 | 按规则选择，得到父代种群 |
| 交配算子 | 交换基因，产生新个体 |
| 变异算子 | 小概率变异，基因改变 |

## 执行流程

1. **编码**：将问题解编码为染色体
2. **初始化种群**：随机生成初始种群
3. **适应值评价**：计算每个染色体的适应值
4. **选择种群**：根据适应值选择优秀个体
5. **种群交配**：交叉操作产生新个体
6. **种群变异**：小概率变异操作

## 编码方式

编码方式影响交配和变异操作：

- 二进制编码
- 实数编码
- 整数编码
- 排列编码
