GzDoc 是一个企业级智能文档处理平台，基于 AI 的智能文档管理与问答系统。

## 核心功能

### 1. 智能文档管理
- 文档上传与存储
- 文档解析与提取
- 文档分类与标签

### 2. 智能问答系统
- 基于 RAG 的文档问答
- 多轮对话支持
- 上下文理解

### 3. 场景化应用
- 金融研报分析
- 法律文档审查
- 医疗文档处理

## 技术架构

### 平台层
- Java Spring Boot
- PostgreSQL 数据库
- Redis 缓存

### AI 层
- Python FastAPI
- LangChain
- Weaviate 向量数据库
